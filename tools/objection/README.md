# アウト返し・競合対策

WorkKitの既存ツール入口から利用する正式モジュール。

採用版：`local-rule-composition-20261031-v1`（2026-10-31修正）。登録済みの完成原稿と会話フローを優先し、未収録の組み合わせには確認用の共通ルール台本を表示する。原稿の作者・参照ID・版・保存スキーマを維持。

JS・CSSは同じディレクトリへの相対参照、トップへの戻りは`../../`。GitHub Pagesの`/workkit/`を含むベースパスで使用できる。外部AI API・新規依存パッケージなし。

保存はブラウザの既存専用localStorage領域を継続使用し、他ツールの履歴を変更しない。別オリジンのローカルプレビューで保存した履歴はJSONの書き出し・読み込みで移す。同じオリジンの同一保存キーはパスによらず共有される。

ルール外の意図は確認質問になる。心理は仮説、顧客の返答は想定例。料金・契約・日程は確認が必要。連絡停止はローカルで保持し、外部顧客DBとは同期しない。

統合時の変更は、既存入口の置換、本体へ戻るリンク、公開状態に合わせた案内文、原稿メタデータ内の私有PCパスの除去のみ。台詞・生成処理・CSSは承認済み採用版を維持する。
